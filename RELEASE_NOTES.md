# LinnStrument Custom Firmware 2.3.4-x6

This is an unofficial custom firmware based on LinnStrument firmware 2.3.4. It has been tested on LinnStrument 200.

## Highlights

- 3x4 Scalar Layout with horizontal +/-3-semitone and vertical +/-4-semitone geometry.
- Scale-aware Scalar Swipe with exact-MIDI-note LED feedback.
- Per-split Dynamic Strum with symmetric left/right Voicing and Strum roles.
- Voicing-aware eight-row mapping that preserves inversions and open voicings.
- Dynamic Sustain, per-gesture Snapshot, Retrigger, and Legato integration.
- Global Settings recovery behavior and Split/mode-switch cleanup.

The 3x4 Scalar Layout was inspired by Mike Gao's Polyplayground app.
