# LinnStrument 2.3.4-x6 Release Baseline

- Base firmware: LinnStrument OS 2.3.4
- Target board: Arduino Due (`arduino:sam:arduino_due_x`)
- Arduino SAM Boards: 1.6.11
- Build entry point: `scripts/compile-firmware.sh`
- Hardware validation: LinnStrument 200
- Public release tag: `v2.3.4-x6`

The release is built from the current working tree after the final hardware-tested\changes are frozen. The offline Arduino toolchain remains local and is ignored by
Git; it is not part of the public repository.
